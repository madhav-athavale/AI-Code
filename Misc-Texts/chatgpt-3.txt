While looping thru a for loop in python I want to print the next line if the current line contains a particular string. How?

You want to detect a line with a match, then print the next line. There are a few clean ways to do this depending on how you’re reading the data.

✅ Option 1: Using index (simplest for lists)
lines = [
    "hello",
    "match this line",
    "this is next line",
    "another line"
]

for i in range(len(lines) - 1):
    if "match" in lines[i]:
        print(lines[i + 1])
✔ Easy
✔ Safe (avoids index out of range)

✅ Option 2: Using zip (Pythonic way)
for current, nxt in zip(lines, lines[1:]):
    if "match" in current:
        print(nxt)
✔ Cleaner
✔ No manual indexing

✅ Option 3: Reading from a file (very common use case)
with open("file.txt") as f:
    prev = None
    for line in f:
        if prev and "match" in prev:
            print(line.strip())
        prev = line
✔ Memory efficient (good for large files)

✅ Option 4: Using iterator (advanced, elegant)
lines_iter = iter(lines)

for line in lines_iter:
    if "match" in line:
        print(next(lines_iter, None))
✔ Uses iterator directly
✔ next(..., None) avoids crash at end

⚠️ Edge case to watch
If the matching line is the last line, there is no “next line”.

All above solutions handle it safely except naive indexing.

For files → use Option 3

For lists → use Option 2 (zip)

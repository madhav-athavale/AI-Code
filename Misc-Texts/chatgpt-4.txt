✅ Method 1: Formula (no coding)
Assume your data is in Column A.

Step 1: Use this formula
In a new sheet (or empty area), enter in B1:

=INDEX($A:$A,(ROW()-1)*6 + COLUMN())
Step 2: Drag

Then drag down

(ROW()-1)*6 jumps every 6 rows

COLUMN() picks the next item within that group

import pdfplumber
import pandas as pd
import re

data = []

with pdfplumber.open("input.pdf") as pdf:
    text = ""
    for page in pdf.pages:
        text += page.extract_text() + "\n"

# Split into claim blocks

for claim in claims:
    if claim.strip() == "":

🧠 Improved script (handles your exact format)
import pdfplumber
import pandas as pd
import re

with pdfplumber.open("sample.pdf") as pdf:
    text = "\n".join(page.extract_text() or "" for page in pdf.pages)

# Clean noise
text = re.sub(r"https?://\S+", "", text)  # remove URLs
text = re.sub(r"\d{1,2}/\d{1,2}/\d{2,4},.*", "", text)  # remove timestamps

# Split claims
claims = re.split(r"Medical claim", text)

results = []

for claim in claims:
    claim = claim.strip()
    if not claim:
        continue

    # Normalize spacing
    claim = re.sub(r"\n+", "\n", claim)

    # Extract fields (robust to line breaks)
    date_match = re.search(r"Date of service\s*\n?\s*([0-9/]+)", claim)
    provider_match = re.search(r"Provider\s*\n?\s*([A-Za-z .]+)", claim)
    amount_match = re.search(r"\$\s*([0-9]+\.[0-9]+)", claim)

    results.append({
        "Date of Service": date_match.group(1) if date_match else "",
        "Provider": provider_match.group(1).strip() if provider_match else "",
        "Amount": float(amount_match.group(1)) if amount_match else None
    })

df = pd.DataFrame(results)

# Remove empty rows (if any)
df = df[df["Date of Service"] != ""]

df.to_excel("output.xlsx", index=False)

print(df)

🌳 2. Binary Search Tree (BST)
🔹 Rule
Left < Root < Right
🔹 Example
        10
       /  \
      5    15
     / \     \
    2   7     20
🔹 Python implementation (insert + search)
class BST:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

    def insert(self, val):
        if val < self.value:
            if self.left is None:
                self.left = BST(val)
            else:
                self.left.insert(val)
        else:
            if self.right is None:
                self.right = BST(val)
            else:
                self.right.insert(val)

    def search(self, val):
        if self.value == val:
            return True
        elif val < self.value and self.left:
            return self.left.search(val)
        elif val > self.value and self.right:
            return self.right.search(val)
        return False

# usage
root = BST(10)
root.insert(5)
root.insert(15)
root.insert(7)

print(root.search(7))  # True

🌳 4. Trie (Prefix Tree)
🔹 Structure (words: "cat", "car")
        (root)
         |
         c
         |
         a
        / \
       t   r
🔹 Python implementation
class TrieNode:
    def __init__(self):
        self.children = {}
        self.end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.end = True

    def search(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.end

# usage
t = Trie()
t.insert("cat")
t.insert("car")

print(t.search("cat"))  # True
print(t.search("cap"))  # False

how to remove secret from commit

If you’ve accidentally committed a secret (API key, password, token) to Git, you need to do two things:

⚠️ 1) Remove it from Git history
⚠️ 2) Rotate (invalidate) the secret immediately

I’ll walk you through both.

🚨 Step 0: Rotate the secret FIRST
Before touching Git:

Go to the service (AWS, API provider, etc.)

Revoke / regenerate the key

👉 Even if you delete it from Git, it may already be exposed.

✅ Case 1: Secret in the LAST commit (not pushed)
Fix quickly:
git reset --soft HEAD~1
This “undoes” the last commit but keeps changes

Then:

# remove secret from file
git add .
git commit -m "clean commit"
✅ Case 2: Secret already committed (and maybe pushed)
You must rewrite history.

🔥 Best tool: git filter-repo
Install:

pip install git-filter-repo
Remove a specific string (secret)
git filter-repo --replace-text <(echo 'SECRET_STRING==>REMOVED')
OR remove a file entirely
git filter-repo --path secrets.txt --invert-paths
Then force push:
git push origin --force
⚠️ Important warnings
This rewrites history → affects collaborators

Everyone must re-clone or reset

✅ Case 3: Public repo on GitHub
After cleaning:

Force push cleaned repo

Go to GitHub

Request cache removal (optional but safer)

🔍 Verify it's gone
git log -p | grep "SECRET"
or

git grep "SECRET" $(git rev-list --all)
🛡️ Prevent this in future
1. Use .gitignore
.env
secrets.json
2. Use environment variables
Instead of:

API_KEY = "abc123"
Use:

import os
API_KEY = os.getenv("API_KEY")
3. Pre-commit hooks (recommended)
Install:

pip install pre-commit
Use tools like:

detect-secrets

gitleaks

👍 Quick decision guide
Situation	What to do
Not committed yet	Just edit file
Last commit only	git reset --soft
Older commits	git filter-repo
Already pushed	Rewrite + force push + rotate secret

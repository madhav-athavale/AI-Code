

You can invoke an AWS Lambda function from the AWS CLI using the aws lambda invoke command. By default, the invocation is synchronous (waits for the function to finish and returns the response). 

Invoke a Lambda function synchronously
aws lambda invoke \
    --function-name my-function \
    --cli-binary-format raw-in-base64-out \
    --payload '{"name":"Bob"}' \
    response.json
Example output:

{
    "StatusCode": 200,
    "ExecutedVersion": "$LATEST"
}
The function's response will be written to response.json. 

Invoke a Lambda function asynchronously
aws lambda invoke \
    --function-name my-function \
    --invocation-type Event \
    --cli-binary-format raw-in-base64-out \
    --payload '{"name":"Bob"}' \
    response.json
A successful asynchronous invocation returns status code 202. 

Invoke using a payload file
Create payload.json:

{
    "customer_id": 123,
    "action": "process"
}
Then run:

aws lambda invoke \
    --function-name my-function \
    --cli-binary-format raw-in-base64-out \
    --payload file://payload.json \
    response.json

If you're using a specific AWS profile or region
aws lambda invoke \
    --function-name my-function \
    --profile myprofile \
    --region us-east-1 \
    --cli-binary-format raw-in-base64-out \
    --payload '{}' \
    response.json
List your Lambda functions
aws lambda list-functions
Get the function names only
aws lambda list-functions \
    --query 'Functions[*].FunctionName' \
    --output text

How to upload lambda function code using cli

To upload new code to an existing AWS Lambda function using the AWS CLI, first create a ZIP file containing your Lambda code, then use update-function-code. 

1. Create the ZIP file
For a Python Lambda:

zip -r lambda_function.zip .
Make sure your handler file is at the root of the ZIP. 

2. Upload the ZIP to Lambda
aws lambda update-function-code \
    --function-name my-function \
    --zip-file fileb://lambda_function.zip
This updates the $LATEST version of the function. 

3. Upload code from S3 instead of a local ZIP
If your deployment package is already in S3:

aws lambda update-function-code \
    --function-name my-function \
    --s3-bucket my-deployment-bucket \
    --s3-key lambda_function.zip
Lambda can pull the deployment package from S3 when updating the function. 

4. Publish a new version after upload
aws lambda update-function-code \
    --function-name my-function \
    --zip-file fileb://lambda_function.zip \
    --publish
This uploads the code and creates a new numbered Lambda version. 

5. Verify the update
aws lambda get-function \
    --function-name my-function
Or invoke it:

aws lambda invoke \
    --function-name my-function \
    --cli-binary-format raw-in-base64-out \
    --payload '{}' \
    response.json

how to install new lambda function using cli

To create a new AWS Lambda function from the AWS CLI, you need:

A ZIP file containing your code.

An IAM execution role for Lambda.

The aws lambda create-function command. 

Step 1: Create a simple Python Lambda
Create lambda_function.py:

def lambda_handler(event, context):
    return {
        "statusCode": 200,
        "body": "Hello from Lambda!"
    }
Create the ZIP:

zip lambda_function.zip lambda_function.py
Step 2: Create an IAM Role (if you don't already have one)
You can list existing roles:

aws iam list-roles
Look for a Lambda execution role, or create one in the AWS Console with the policy:

AWSLambdaBasicExecutionRole

Step 3: Create the Lambda Function
Replace the role ARN with your own:

aws lambda create-function \
    --function-name my-python-lambda \
    --runtime python3.12 \
    --handler lambda_function.lambda_handler \
    --zip-file fileb://lambda_function.zip \
    --role arn:aws:iam::123456789012:role/lambda-execution-role
The handler format is:

<python_file_name>.<function_name>
So:

lambda_function.lambda_handler
means:

File: lambda_function.py

Function: lambda_handler 

Step 4: Invoke the Function
aws lambda invoke \
    --function-name my-python-lambda \
    --cli-binary-format raw-in-base64-out \
    --payload '{}' \
    response.json
View the result:

cat response.json
Step 5: Update the Code Later
After changing the code:

zip lambda_function.zip lambda_function.py

aws lambda update-function-code \
    --function-name my-python-lambda \
    --zip-file fileb://lambda_function.zip
Useful Commands
List functions:

aws lambda list-functions
Get function details:

aws lambda get-function \
    --function-name my-python-lambda
